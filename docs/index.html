emptyOutObject(obj, overrides)

Restores all non-null fields in an object to default values.

  • Array fields are reset to [].
  • Object fields are reset to {}.
  • Other fields are set to the empty string.

These default values can be be overridden on a per-field basis by supplying key/value pairs in the optional overrides parameter, where the key is the field name, and the value is the default value which should be used.

Function fields are assumed to be Mithril streams and will have their values reset, too, per the above.

Fields with null values will remain null.

IMPORTANT! This function modifies the object!

Parameters:
NameTypeDescription
objObjectthe object to reset
overrides?Objectkey/value pairs to use as non-standard defaults
Examples: 
  emptyOutObject({"a": "x", "b": [123], "c": {"z": 456}))
  // => {"a": "", "b": [], "c": {}}

  emptyOutObject({"n": 123, "p": "foo", "q": null}, {"n": 0}
  // => {"n": 0, "p": "", "q": null}

getByPath(object, path)

Returns a possibly deeply-nested field from a data structure. The path parameter is a series of field names separated by slashes, each element digging a level down into the object. Both Objects and Arrays are supported in any combination.

If the path specifies a field with a null value, there's no way to tell if this function succeeded or not.

Fields which are functions are assumed to be Mithril streams, and should be handled correctly.

Parameters:
NameTypeDescription

Returns: (Object|number|string|Array) - whatever data is at the given path, or null if either parameter is null or path contains a field name not in the object
Example: 
  getByPath({"a": {"b": 1, "c": {"d": 3}}}, "a/c/d") // => 3

Typeahead

Mithril component for a text box with typeahead functionality. The client is responsible for providing the suggestions via the findMatches vnode attribute. The return value from that function should conform to the following data structure:

{
  "suggestions": [
    { "name": ..., "start": ..., "len": ... },
    { "name": ..., "start": ..., "len": ... },
  ]
}
  • name is the suggestion to show the user
  • start is the 0-based starting position of the match of the search string within name
  • len is the length of the search string
VNode Attributes:
NameTypeDescription
findMatchesfunction(searchString:string, data:Object)callback function to get suggestions
onItemSelectfunction(target:DOMElement)Callback when user selects a choice. target will be the selected DOM element, with data-x attribute for each field returned by the findMatches callback. For example, if findMatches populates the suggestions array with {id: 12, name: "abc"} and the user selects that choice, then target.dataset.id === 12 and target.dataset.name === "abc". If the user cancels the search, target == null.
placeholder?stringplaceholder text for the input widget
